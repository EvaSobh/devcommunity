# DevCommunity Capstone Submission

**Student:** Eva Sobh

**Project:** DevCommunity

**Live Deployment:** https://devcommunity-eta.vercel.app

## Project Summary

DevCommunity is a full-stack developer community platform built with Next.js, MongoDB Atlas, Mongoose, Auth.js, Zod, and Tailwind CSS.

The project includes developer profiles, communities, technical blogs, comments, bookmarks, authentication, authorization, search, filtering, sorting, pagination, responsive design, and production deployment.
